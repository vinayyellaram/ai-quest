# Weekly Schedule Template (12–15 hrs/week)

Adjust days to your life. Consistency beats intensity.

## Sample week

| Day | Time | Activity |
|-----|------|----------|
| **Mon** | 1.5h | Course/video (theory) + notes in `notes/week-XX.md` |
| **Tue** | 1.5h | Hands-on coding (follow checklist) |
| **Wed** | 1.5h | Hands-on coding (continue project) |
| **Thu** | 1h | Review notes, flashcards, re-implement one concept from memory |
| **Fri** | 1.5h | Small exercise or Kaggle/dataset practice |
| **Sat** | 4h | **Project block** — main portfolio work |
| **Sun** | 1h | Read one blog/paper; update GitHub README |

**Total: ~12.5 hours**

---

## Phase-specific focus

### Phase 1 (Weeks 1–4)
- 60% Python practice
- 30% math intuition (videos)
- 10% environment setup

### Phase 2 (Weeks 5–10)
- 40% scikit-learn / PyTorch coding
- 40% course lessons (fast.ai or Andrew Ng ML)
- 20% math review as needed

### Phase 3 (Weeks 11–18)
- 70% building projects
- 20% reading docs (OpenAI, LangChain, HF)
- 10% theory (RAG papers, eval methods)

### Phase 4 (Weeks 19–24)
- 50% portfolio projects
- 30% job applications + networking
- 20% interview prep

---

## Daily routine (when you sit down)

1. **5 min** — Read yesterday's notes
2. **45–90 min** — Deep work (no tabs except docs)
3. **10 min** — Write what you learned in `notes/`
4. **5 min** — Commit to GitHub if you wrote code

---

## Rules that keep you on track

1. **One primary course at a time** — finish or pause before starting another
2. **Ship every 2 weeks** — even a tiny repo counts
3. **No tutorial hell** — after each tutorial, rebuild without looking
4. **Use your stack** — deploy with nginx/Node when it makes sense
5. **Track hours** — log in `notes/learning-log.md`

---

## If you fall behind

- Skip optional items in checklists (marked *optional*)
- Extend Phase 2 by 2 weeks rather than rushing LLMs
- LLM projects matter more for jobs than perfect math scores
